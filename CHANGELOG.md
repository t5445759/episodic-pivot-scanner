# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-09-14

### Added
- Initial release of Episodic Pivot Scanner
- Real-time gap scanner with configurable filters
- Backtesting engine with historical analysis
- Paper trading account with P&L tracking
- Alert system (Email, SMS, Webhooks)
- News catalyst analysis with sentiment
- FastAPI web server and dashboard
- CLI tool for all operations
- Database persistence (SQLite/PostgreSQL)
- Docker and docker-compose setup
- Comprehensive documentation

### Features
- Price filtering ($5 - $500)
- Market cap filtering ($50M - $10B)
- Gap detection (≥ 10%)
- Relative volume detection (≥ 5x)
- Volume filtering (≥ 500k shares)
- Average daily dollar volume filtering (≥ $10M)
- Technical indicators (SMA 10, SMA 20)
- Performance metrics (1W, 1M)
- Composite scoring system
